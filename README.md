# 픽셀올로지

픽셀 게임 세계관의 휴대폰 앱 회원가입 프로토타입과, 어떤 서비스에도 재사용할 수 있는 회원가입 스킬을 담은 저장소입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 픽셀올로지 앱. 가입, 로그인, 탈퇴, 복귀, 게임 상점 화면 |
| `mail-template.html` | Supabase에 넣는 인증 코드 메일 본문 |
| `skills/prodigal-signup/` | 브랜드 규칙 없는 재사용 회원가입 스킬 |
| `.claude-plugin/plugin.json` | 스킬 플러그인 정보 |

## 앱 실행

`index.html`을 브라우저에서 열면 됩니다. 이메일 코드 인증은 Supabase로 실제 동작하고, 계정과 포인트는 아직 가짜 데이터라서 새로고침하면 사라집니다. 구매는 앱 포인트로만 하며 실제 결제는 없습니다.

## 시험 계정

메일을 보내지 않고 코드 `123456`으로 확인합니다.

| 이메일 | 반응 |
|---|---|
| `qwer@gmail.com` | 이미 가입된 계정 |
| `1234@gmail.com` | 40일 전에 탈퇴한 돌아온 유저 |

## 스킬

`skills/prodigal-signup/SKILL.md`에서 시작합니다. 핵심 원칙은 "떠난 사람을 다시 심사하지 않는다. 단, 본인임이 확인된 뒤에 알아본다."입니다. 현재는 이메일 코드 모듈까지 제공합니다.
